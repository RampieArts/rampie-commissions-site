# Rampie — визитка и комиссии

Первая страница — одно окно-визитка. Вторая (`commissions.html`) — меню заказов: каверы, видео, FAQ и контакт.

## Что менять

| Хочешь поменять | Файл |
| --- | --- |
| Ник, описание, ссылки, Discord | `index.html` |
| Опции, цены, FAQ, тексты на странице заказов | `commissions.html` — внутри секций есть комментарии |
| Открыты / закрыты заказы | `data/status.js` — одна строка: `true` или `false` |
| Работы в каруселях | `data/works.js` — просто добавь ссылку на YouTube или X |
| Аватар | положи `assets/avatar.jpg` (или поправь имя в `js/card.js`) |
| Цвета | самый верх `css/styles.css` (`:root`) |

## Работы в карусели

В `data/works.js` два списка: `covers` и `video`. Можно строкой или с названием и тегами:

```js
covers: [
  "https://youtu.be/xxxxxxxxxxx",
  { url: "https://x.com/Rampieeeee/status/1234567890", title: "Cover title", tags: ["tune", "mix"] }
]
```

Теги рисуются на превью вместо старой кнопки OPEN. Клик по ролику по-прежнему открывает его. Кнопка **GRID** разворачивает карусель в сетку.

## Открыты ли заказы

В `data/status.js` одна строка:

```js
window.COMMISSIONS_OPEN = true;
```

`true` — зелёный **OPEN**, `false` — красный **CLOSED**. Меняется на визитке и на странице заказов. На GitHub: поправил файл → commit → push.

## Цвета

Тёмный фон, холодный приглушённый фиолет. Ярче всего ник, рамка и кнопки COMMISSIONS / ORDER.

- `--void` — фон страницы
- `--panel` — фон окна
- `--accent-hi` — ник и акценты
- `--fill` — заливка большой кнопки

## Как смотреть

Открой `index.html` или зайди на `http://localhost:5173`.
